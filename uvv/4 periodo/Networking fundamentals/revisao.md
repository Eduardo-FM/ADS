
## Dispositivos 

Uma rede só faz sentido se tiver dispositivos finais ligadas a ela. 

Se tem um endereco IP é um host.

Se utiliza um endereco de rede é um endpoint, e entao um host.

Se um dispositivo desktop tiver uma funcao para ser um roteador ele sera um dispositivo intermediário.
